# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report suspected vulnerabilities privately to the FlowGuard project maintainers and include:

- A description of the issue
- Steps to reproduce it
- The affected feature
- Any suggested remediation

Confirmed vulnerabilities will be reviewed and addressed where appropriate.

## Supported Versions

FlowGuard is an academic proof-of-concept project. Only the latest version on the default branch is actively maintained.
